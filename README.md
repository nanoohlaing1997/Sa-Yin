# Sa Yin

A personal expense tracker for iOS — record what you spend and earn, and see
where the money actually went each month.

Built with **Expo (React Native) + TypeScript**, backed by **Firebase Auth**
and **Cloud Firestore**.

## Features

- Email/password sign up and sign in, with the session persisted on-device
- Add, edit, and delete expenses and income
- Pre-set categories with colours and icons
- Monthly report: net balance, income vs expenses, and a donut breakdown of
  spending by category
- Transactions list grouped by day, with per-day totals
- Month switcher shared across the report and the list
- Live updates — Firestore pushes changes to every screen as they happen

## Getting started

### 1. Install

```bash
npm install
```

### 2. Create a Firebase project

1. Go to the [Firebase console](https://console.firebase.google.com) and create
   a project.
2. **Build → Authentication → Sign-in method** → enable **Email/Password**.
3. **Build → Firestore Database** → create a database (production mode).
4. **Project settings → Your apps** → add a **Web** app (`</>`), and copy the
   config values.

### 3. Configure

```bash
cp .env.example .env
```

Fill in the values from the Firebase web app config. They're read at build time
via Expo's `EXPO_PUBLIC_*` convention — public by design, with access enforced
by the Firestore rules below.

### 4. Publish the security rules

`firestore.rules` restricts every document to the user who owns it. Paste it
into **Firestore → Rules** in the console, or deploy with the Firebase CLI:

```bash
firebase deploy --only firestore:rules
```

### 5. Run

```bash
npx expo start --ios     # iOS simulator (needs Xcode)
npx expo start           # scan the QR code with Expo Go on your iPhone
```

If you edit `.env`, restart with `npx expo start -c` to clear the Metro cache.

## Data model

```
users/{uid}/transactions/{transactionId}
  type        'expense' | 'income'
  amount      number (always positive; `type` carries the direction)
  categoryId  string   (see src/lib/categories.ts)
  note        string
  date        Timestamp
  createdAt   Timestamp
  updatedAt   Timestamp
```

Categories are defined in code rather than stored, so they stay consistent and
cost no reads.

## Project layout

```
app/                  expo-router routes (file-based navigation)
src/components/       Reusable UI — buttons, fields, donut chart, rows
src/lib/              Firebase client, auth context, Firestore access, helpers
src/theme.ts          Colours, spacing, radii, shadows
firestore.rules       Per-user access rules
```

## Shipping to the App Store

Builds go through [EAS](https://docs.expo.dev/build/introduction/):

```bash
npm install -g eas-cli
eas login
eas build --platform ios
eas submit --platform ios
```

An Apple Developer account is required.

## Notes

- Amounts are displayed in USD (`src/lib/format.ts`); multi-currency support
  isn't implemented yet.
- `ios/` and `android/` aren't committed — this is a managed Expo project, and
  native directories are generated by `npx expo prebuild` or EAS.
